# Stone Family Recipes — scanned manuscript

Place the **199-page original family cookbook scan** here, named:

`stone-family-recipes.pdf`

The Recipe Blueprint site links individual restored recipes directly to the page of the **original manuscript scan**, using:

`books/stone-family-recipes.pdf#page=26`

The page reference in the 280-page restored cookbook is separate and is displayed alongside it; do not use the restored-book page number for links to this scanned PDF.

The cookbook JSON is stored at `data/stone-family-recipes.json` (manifest), with two recipe-data parts in the same folder. Some directions were reconstructed by AI; the site labels those steps and preserves their original transcriptions.

**Important:** A scan of a personal family album may include personal correspondence or addresses; review it before publishing publicly.
